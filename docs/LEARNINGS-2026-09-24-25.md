## Harness / engineering laws (each cost real tokens)
1. **DESTRUCTIVE-REGEX-EDIT** (empor #1): a block-matching CSS regex with optional
   trailing groups swallowed the theme-dot rules; gray "broken" swatches rode TWO full
   two-judge rounds (~166 judgments). Cure: after any broad CSS edit, run a rendered
   probe of the affected selectors BEFORE any expensive gate (theme-dots-probe.js).
2. **The SW two-reload trap** (empor #2): a new build can be served by the server and
   still invisible on the CEO's first reload — the OLD service worker answers first,
   the new one installs behind it. Cure: /api/version build stamp shown in the footer
   (staleness = one glance), network-first SW, cache-version bump per release.
3. **Bare `:root` after the dark block** = file-order override of dark-mode tokens.
   Pinned by test_theme_layering; scope appended token overrides.
4. **`\bbtn-` focus-gate regex** spawns phantom .btn-x:focus-visible demands from
   compound classes (icon-btn-lang). Don't name classes `<x>-btn-<y>`.
5. **Generated CSS token blocks need SEMICOLON joins** — commas collapse the whole
   list into one custom property (the "palettes don't apply" bug).
6. **html[x] :root is a descendant selector** — html cannot descend from itself;
   compound `html[x]:root` is the correct scoping.
7. **MiMo v2.6 is a reasoning model**: with a small max_tokens it burns the budget on
   invisible chain-of-thought and returns EMPTY (finish_reason=length). Give it a big
   budget (20K+) and LET it think; probe with a budget ladder.
8. **The omx engine lane (127.0.0.1:8817) strips image parts** — vision never rides it
   (bridge /v1/responses drops image content; filed to Platform). Working vision lanes:
   `zcode -p --attach` (GLM-5.3-Flash), `codex exec -i` (gpt-5.6), MiMo via nucbox.
9. **`make a11y-ax` audits AX_BASE/AX_COV defaults** regardless of PORT_A/B — pass env
   explicitly; PY too.
10. **HA is a lexical global** (`const HA` in a classic script): reachable across
    scripts and in evaluate(), NOT on window.
11. **agents die silently mid-mission**; the recovery pattern that worked: snapshot
    commits ("WIP recovery") preserve the tail; inventory the worktree before
    re-dispatching; two deaths on one mission = take it in-house.
12. **The deleted-venv class**: shared infra (a venv worktree) can vanish under you;
    the live server survives on loaded modules while new test runs fail. Rebuild venv
    in the repo worktree (Makefile default PY), verify with the suite.
