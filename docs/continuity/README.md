## Provenance rules

- **Bodies are verbatim.** Nothing was rewritten, summarised or "cleaned up". Front matter
  records the source issue, labels, dates and author.
- **One disclosed edit:** links of the form `https://github.com/simongonzalezdc/healthadvocate/issues/NN` that point
  at another document imported here are rewritten to the local file so the record is
  self-contained. Files with that rewrite say so in their front matter (`edits:`). Links to
  issues *not* imported here are left untouched.
- These files are **history, not current truth**. Where a decision record and the code
  disagree, the code and its tests win; open that as a defect rather than editing this record.
